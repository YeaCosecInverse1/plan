# 00 — SYSTEM MAP

## QUICK START

When I open this repo, I do not read everything.

I ask:

1. **Where am I right now?**
2. **What is my one main technical skill right now?**
3. **What is the next gate?**
4. **What life/admin task is currently blocking me?**
5. **What should I explicitly NOT study yet?**

The current chain is:

**Bangladesh preparation → European Bachelor's → European internships/working-student work → European full-time engineering → Japan preparation → Japanese engineering job → HSP/PR planning → post-PR life.**

The phases are connected. I should not optimize one phase by damaging the next one.

## GATES

I move forward when I can:

- explain the concept
- do the task without a tutorial holding my hand
- build something with it
- debug a normal failure
- document what I did
- repeat it later

Watching a course is not a gate.

## ONE-NEXT-TASK RULE

The whole roadmap can be huge. Today's task should not be.

At any moment I should have:

**Current phase → current skill → current task → next gate.**

Everything else can wait.
