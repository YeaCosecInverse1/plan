# My Journey Plan

This repo is the public documentation of the plan I am actually trying to follow.

I am not writing this as a perfect career manual. I am writing it so I can open the repo, see where I am, know what I should do next, and keep the whole Bangladesh → Europe → Japan → PR path connected.

Some parts are current plans. Some are long-term targets. Immigration, university rules, costs, visas, job markets and software change, so anything time-sensitive has to be re-checked before I act on it.

## The rule that connects everything

**Learn → practice → build → break → fix → explain → pass the gate → move on.**

I do not need to finish every resource I find online. I need to become capable.

## Important

Europe is not one immigration system. Student work rights, residence rules, tuition, scholarships and post-study routes depend on the country and sometimes the exact permit.

Japan's HSP and PR rules also change. This repo treats the official Japanese Immigration Services Agency / Ministry of Justice material as the legal source of truth, and third-party calculators as planning aids only.
