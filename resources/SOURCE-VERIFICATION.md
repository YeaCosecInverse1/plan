# ADD-ON — SOURCE VERIFICATION

## QUICK START

I am building a long plan in a world where some facts stay stable for years and other facts can change between applications.

So I separate:

**learning knowledge** from **decision-critical facts**.

Before acting on a legal, financial, admissions or exam rule, I check the current primary source.

## SOURCE HIERARCHY

### Immigration / residence

1. Japanese Immigration Services Agency / Ministry of Justice or the relevant European/national immigration authority.
2. Official embassy/consulate or government page.
3. Official university/employer page for institution-specific requirements.
4. Reputable secondary source for explanation.
5. Forums/social media only for lived experience, never as the final legal authority.

### Technology

1. Official project documentation.
2. Official release notes/version documentation.
3. Reputable technical education.
4. Community discussion.

### Exams

Use the official organization first.

## VERIFIED ANCHORS

### Japan PR / HSP

The Immigration Services Agency's current PR guideline is dated **February 24, 2026**.

It describes a route for people with **70+ points** who satisfy the relevant highly skilled professional conditions and have maintained the required status/points for the applicable three-year framework.

It also describes an **80+ point** route using the applicable one-year framework, again with specific conditions.

I therefore do not write:

> “80 points = automatic PR.”

That is too simplistic.

Source:

https://www.moj.go.jp/isa/applications/resources/nyukan_nyukan50.html

### IELTS

The official IELTS Academic format currently has four components:

- Listening
- Reading
- Writing
- Speaking

The official site lists a total test time of about 2 hours 45 minutes for IELTS Academic and provides official sample materials.

Sources:

https://ielts.org/take-a-test/test-types/ielts-academic-test

https://ielts.org/take-a-test/preparation-resources/sample-test-questions/academic-test

### JLPT

The official JLPT site currently describes five levels:

N5 → N4 → N3 → N2 → N1

The current 2026 schedule listed by the official site is July 5 and December 6. Test availability outside Japan can vary by city.

The test itself covers language knowledge/reading and listening sections. I should therefore use JLPT as evidence of Japanese ability, not as a complete substitute for speaking and writing practice.

Source:

https://www.jlpt.jp/e/guideline/testsections.html

### AWS

AWS currently provides beginner-oriented Cloud Essentials learning through AWS Training/Skill Builder.

Source:

https://aws.amazon.com/training/learn-about/cloud-practitioner/

https://aws.amazon.com/training/digital/

### Kubernetes

The official Kubernetes documentation currently provides Kubernetes Basics as an interactive tutorial covering cluster creation, application deployment, exposure, scaling, updating and debugging.

The documentation currently lists v1.37 as the latest documentation version.

Sources:

https://kubernetes.io/docs/tutorials/kubernetes-basics/

https://kubernetes.io/docs/home/supported-doc-versions/
