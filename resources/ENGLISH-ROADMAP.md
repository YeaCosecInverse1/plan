# ADD-ON — ENGLISH ROADMAP

## QUICK START

I do not wait until my English is “good enough” before learning technical material.

I improve English by using it.

The fuller skill-by-skill resource choice, coverage estimate and paid alternative live in [LEARNING-SYSTEM.md](LEARNING-SYSTEM.md). This file keeps the day-to-day English routine.

Daily:

- 15–30 min reading/listening
- technical documentation
- a small vocabulary/phrase review
- 5–10 min speaking when practical

IELTS preparation remains the exam-specific track.

## STAGE 1: SURVIVAL ENGLISH

I need to understand:

- basic instructions
- dates/times
- directions
- forms
- appointments
- money
- university messages

## STAGE 2: ACADEMIC ENGLISH

Practice:

- reading long passages
- identifying the main argument
- summarizing
- writing structured answers
- listening to lectures

## STAGE 3: TECHNICAL ENGLISH

Every week:

- read one technical document
- write a short summary
- explain one technical topic aloud
- write useful commit/issue/README text

## STAGE 4: PROFESSIONAL ENGLISH

Practice:

- meetings
- presentations
- technical disagreement
- incident reports
- bug reports
- professional email/chat
- interview answers

## IELTS

Use the current official IELTS test format and preparation materials:

https://ielts.org/

Do not assume an old test format or score requirement remains unchanged.

## WEEKLY GATE

Record a 5–10 minute explanation of something I learned.

Then ask:

- Did I speak continuously?
- Did I use the correct technical words?
- Did I explain cause → effect?
- Did I notice repeated grammar mistakes?
- Could another engineer understand me?

The goal is communication, not a fake accent.
