# ADD-ON — JOB SEARCH SYSTEM

## QUICK START

I treat job hunting as a technical project.

### Every week

- find relevant vacancies
- compare requirements
- improve one missing skill
- submit targeted applications
- practice interviews
- record results

## TRACK

Company | Role | Location | Stack | Requirements | Gap | Applied | Stage | Result

## CV RULE

Every important bullet should answer:

**What did I do, with what, and what changed?**

Do not fill the CV with technology names I cannot explain.

## INTERVIEW RULE

For each project I should be ready to explain:

- problem
- architecture
- trade-offs
- failure
- debugging
- security
- cost
- scaling
- what I would change

## EUROPE → JAPAN

When Japan becomes an actual target, maintain:

- English CV
- Japanese CV where appropriate
- project portfolio
- technical stories
- references
- degree documents
- employment evidence
- Japanese certification evidence
