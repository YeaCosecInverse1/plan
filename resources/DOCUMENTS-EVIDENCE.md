# ADD-ON — DOCUMENTS / EVIDENCE SYSTEM

## QUICK START

I maintain one organized evidence archive from the beginning instead of trying to reconstruct my life five years later.

## FOLDERS

Suggested structure:

- 01-Identity
- 02-Education
- 03-Immigration
- 04-Finance
- 05-Employment
- 06-Japanese
- 07-Professional-Certifications
- 08-Applications
- 09-Residence
- 10-PR

## EMPLOYMENT EVIDENCE

Keep lawful copies of:

- contracts
- experience certificates
- payslips
- tax evidence
- promotion records
- job descriptions
- reference information

Keep a simple timeline:

date → employer → title → duties → technology → evidence location.

## PROJECT EVIDENCE

For every important project:

- problem
- architecture
- implementation
- failure
- fix
- result
- lessons

Do not store confidential employer material.

## BACKUPS

Use at least:

- working copy
- local backup
- encrypted off-device backup

Test restoration occasionally.
