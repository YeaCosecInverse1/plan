# 07 — EUROPEAN JOB PLAN

## QUICK START

My European job is not just a salary source. It is the bridge between **student** and **experienced engineer**.

The target is not a magic job title.

### Good target families

- Cloud Engineer
- DevOps Engineer
- Infrastructure Engineer
- Platform Engineer
- SRE
- Systems Engineer
- Backend/Software Engineer with meaningful infrastructure ownership
- Production/Cloud Support with a genuine engineering progression

## BEFORE APPLYING

I need:

- one-page CV where practical
- LinkedIn/profile
- GitHub
- project explanations
- technical interview notes
- references
- degree/transcript evidence
- work authorization information for the country
- salary expectations based on current local market research

## JOB SEARCH SYSTEM

For every vacancy record:

- company
- country/city/remote
- role
- tech stack
- requirements
- missing skills
- salary if published
- visa/work authorization
- application date
- response
- interview stage
- reason for rejection when known

Patterns matter more than individual rejections.

## FIRST PROFESSIONAL YEAR

I am learning how production actually works.

Focus:

- code review
- tickets
- Git workflows
- deployments
- CI/CD
- monitoring
- incidents
- documentation
- security
- communication
- change management

I keep a private work log that does not expose confidential company information.

## SECOND PROFESSIONAL YEAR

Move toward ownership:

- services
- automation
- reliability
- infrastructure
- architecture participation
- cost
- security

Start serious Japan market research.

## THIRD PROFESSIONAL YEAR

Build a coherent specialization and prepare the Japan transition.

I should be able to tell a simple story:

> I can operate and improve production systems, and I have several years of evidence showing it.

## EVIDENCE ARCHIVE

Keep copies of:

- employment dates
- contracts where lawful
- experience certificates
- payslips/tax records where relevant
- job descriptions
- promotion records
- major project summaries
- references
- degree documents
- certifications
- Japanese-language certificates

Do not take confidential company code or secrets.

## JAPAN PREPARATION TRIGGER

Start serious Japan applications when I have:

- relevant professional experience
- a coherent specialization
- suitable Japanese ability for target jobs
- a clean CV/portfolio
- documented employment
- a realistic relocation budget
