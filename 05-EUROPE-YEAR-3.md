# 05 — EUROPE YEAR 3

## QUICK START

**Main goal: become employable for real engineering work.**

### Learn

- AWS/cloud deeper
- Terraform
- CI/CD
- observability
- security
- Kubernetes
- reliability
- production operations

### Career

- stronger internship/working-student role
- graduate-job applications
- interview preparation
- references

### Build

One integrated production-style system.

### Japanese

Continue toward N2/N1 depending on pace. Add workplace vocabulary.

## TECHNICAL ORDER

Do not start with Kubernetes because it looks impressive.

First prove:

Linux + networking + Docker + cloud + CI/CD.

Then:

Kubernetes → observability → reliability/security.

## CLOUD / INFRASTRUCTURE

I should be able to:

- design a basic cloud network
- deploy services
- manage identity securely
- automate infrastructure with Terraform
- configure CI/CD
- inspect logs/metrics
- understand failure modes
- control basic cloud costs

## KUBERNETES GATE

Before going deep, I should already understand:

- containers
- networking
- DNS
- storage
- HTTP
- Linux processes
- resource constraints

Then learn:

Pod → Deployment → Service → ConfigMap/Secret → probes → storage → ingress → scaling → rollback.

## OBSERVABILITY

Learn the difference between:

- logs
- metrics
- traces

Then practice:

- dashboards
- alerts
- incident investigation
- useful SLIs/SLOs

## GRADUATE JOB PREP

Create evidence, not vague claims.

For every serious project/job:

- what I built
- why
- architecture
- failure
- fix
- result
- what I would change

Prepare technical interview explanations in English.

## YEAR-END GATE

I should have:

- degree progress on track
- meaningful internship/working-student evidence
- several strong projects, not dozens
- cloud/infra portfolio
- CV + LinkedIn/GitHub ready
- references where possible
- a realistic job target list
