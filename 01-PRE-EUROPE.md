# 01 — PRE-EUROPE PLAN

## QUICK START: WHAT I DO NOW

Until I actually leave Bangladesh, my job is to become **technically useful, academically ready, financially prepared and personally independent**.

### Current priority order

1. University/admission work.
2. Computer + Linux + Git + Python foundation.
3. English/IELTS.
4. Basic networking + SQL + HTTP.
5. Money/document preparation.
6. Daily-life independence.
7. Japanese as a controlled side track.

I do **not** need AWS + Kubernetes + AI right now.

## 1. COMPUTER FOUNDATION

I need to stop being dependent on tutorials for ordinary computer tasks.

I should be able to:

- install an operating system
- understand filesystems and partitions at a basic level
- manage files and permissions
- use a terminal
- install/remove software
- understand processes and services
- diagnose storage/RAM/CPU/network problems
- use SSH
- read logs
- make and restore backups
- understand basic privacy/security
- use Git
- understand what a server is doing

### Gate

Give myself a fresh Linux environment and complete normal setup without copying a full setup guide line-by-line.

## 2. TECHNICAL LEARNING ORDER

### Stage A
Computer fundamentals → Linux → shell → Git.

### Stage B
Python → files → JSON/CSV → APIs → CLI → logging → tests.

### Stage C
Networking → DNS → TCP/UDP → HTTP/HTTPS → SSH → firewalls.

### Stage D
SQL/PostgreSQL → backend concepts → FastAPI.

### Stage E
Docker.

Only after this foundation is solid do I seriously start AWS/Terraform/Kubernetes.

## 3. PROJECT

Build my small **Server Toolkit**.

It should inspect:

- OS/kernel
- CPU/RAM
- disks/filesystems
- network interfaces
- IP/routes
- services
- logs
- storage usage

It can later add safe maintenance utilities.

The point is not to make a beautiful app. The point is to prove that I can operate and automate a Linux machine.

## 4. ENGLISH

My English does not need to be perfect before I touch technical material.

Instead:

- learn difficult concepts slowly
- keep a vocabulary/phrase list
- read official docs
- write commit messages in English
- write README files in English
- explain what I built aloud
- use subtitles/transcripts when needed
- gradually reduce translation dependence

I keep IELTS as the structured exam track, but technical English becomes daily exposure.

## 5. JAPANESE

Bangladesh is not the phase where Japanese gets to consume my whole schedule.

Default:

**20–30 minutes/day when possible.**

Priority:

Kana → basic grammar → core vocabulary → listening → graded reading.

If university/admission/IT work becomes overloaded, Japanese time can temporarily drop.

## 6. DAILY-LIFE INDEPENDENCE

Before leaving, I should know how to:

- cook several cheap meals
- grocery shop and compare unit prices
- wash clothes
- clean a room/bathroom
- maintain basic hygiene and routine
- manage a weekly budget
- use public transport independently
- navigate with maps
- make appointments
- communicate basic needs
- keep important documents organized
- recognize scams
- use banking safely
- handle a lost phone/wallet/passport emergency
- pack for travel
- sleep and eat on a reasonably stable schedule

I do not want my first week in Europe to become a life-skills bootcamp.

## 7. MONEY

Build a departure budget containing:

- tuition/deposit
- visa/application costs
- flight
- housing deposit
- first-month living expenses
- local transport
- food
- phone/SIM
- insurance where applicable
- study materials
- emergency reserve

Do not assume a student job will rescue an underfunded move.

Country-specific student work rules and proof-of-funds requirements must be checked for the exact destination before applying.

## 8. DOCUMENTS

Create both encrypted digital copies and sensible physical copies of important documents.

Typical categories:

- passport
- birth/civil documents
- academic certificates/transcripts
- admission documents
- financial documents
- scholarship documents
- visa documents
- medical/insurance documents where relevant
- accommodation documents
- emergency contacts

Never rely on one USB drive.

## 9. SECURITY

Before departure:

- password manager
- unique passwords
- MFA
- recovery codes
- encrypted backups
- device encryption where practical
- OS updates
- browser security
- phishing awareness
- separate important accounts from disposable accounts

## 10. PRE-DEPARTURE GATE

I am ready to leave when I can answer:

- Where exactly am I going?
- What permit/status am I entering under?
- Where am I staying initially?
- How do I reach it from the airport?
- How do I register locally?
- How do I get a bank/payment method?
- How do I access healthcare?
- What is my monthly budget?
- What happens if my flight/luggage/phone/wallet goes wrong?
- What is my first-week university plan?
- What is my current technical learning target?
